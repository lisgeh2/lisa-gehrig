Quiet pages
===========

This is the finished website, including the smaller, rounded title boxes and three-column desktop layout.

PREVIEW
Unzip this folder, then double-click index.html to open it in your browser.

DEPLOY
Upload index.html to the root/public directory of any static website host.
No build command, dependencies, server, or API keys are needed.
If your host asks for a publish directory, select the folder containing index.html.

EDIT YOUR WRITING
Open index.html in a text editor. Find "const collections" near the bottom.
Replace the sample titles and text with your own. Copy an existing piece entry to add another.
Use \n for a line break and \n\n for a new paragraph or stanza.
The text uses JavaScript backtick strings: escape any literal backtick with a backslash,
and write \${ if you need a literal dollar sign followed by an opening brace.

Change "Quiet pages" in the title and header to rename your website.
All styling and behavior are included in index.html.
