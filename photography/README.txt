STILL — photography site

GET STARTED
Unzip this archive. Open index.html to view the site locally.
To deploy, upload index.html, style.css, app.js, photos.js, and the entire
images folder into your static host's public/root directory. Keep their
relative paths unchanged. If your host asks for a build command, none is
required; the folder containing index.html is the publish directory.
No packages, backend, database, API keys, or ChatGPT account are needed.
Access control is determined by your chosen host.

EDIT YOUR SITE
- index.html: page title, description, and header text.
- app.js: collection titles and stories in the sections array at the top.
- photos.js: each collection's image list, captions, descriptions, and credits.
- style.css: colors, typography, layout, and full-size viewer styling.
- images/: photographs and square preview thumbnails.

Each collection displays the first four images in a 2x2 grid. All images in
that collection are available in the full-size viewer. Each photo entry's
url points to its full image and thumb points to its square preview.
Keep at least four images per collection. Keep the sections array and the
photos array in the same order, with one photo list per section.

To use your own photography, put your files in images/ and update photos.js.
Use descriptive alt text. Update title, photographer, and source as needed.
The source link currently supplies the photographer credit in the viewer.
